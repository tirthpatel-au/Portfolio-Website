# Tirth Patel Portfolio

React portfolio site built with Vite.

## Run

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

## Notes

- Resume download points to `public/Tirth-Patel-Resume.docx`
- Profile image currently uses `public/profile-placeholder.svg`
- Replace the placeholder image with your real photo any time
